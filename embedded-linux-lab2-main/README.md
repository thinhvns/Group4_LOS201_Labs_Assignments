# Embedded Linux LAB-02

Embedded Linux LAB-02 device driver project.

## Contents

- `driver/` - Character device driver source and kernel module
- `logs/` - Test and boot logs
- `output/` - Generated initramfs image
- `rootfs/initramfs/` - ARM root filesystem

## Features

- Character device read/write
- procfs and sysfs interface
- NAND simulator and JFFS2 test
- Automatic driver loading in QEMU
